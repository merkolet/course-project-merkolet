## Детальная трассировка по NFR

### NFR-001: Производительность API
**Влияет на задачи:**
- **STORY-001** (Создание wish) - High: Время создания должно быть ≤ 200ms
- **STORY-002** (Получение списка wishes) - High: Список должен загружаться быстро
- **STORY-003** (Обновление wish) - High: Обновление должно быть отзывчивым
- **STORY-004** (Удаление wish) - High: Удаление должно быть быстрым
- **TASK-005** (Load testing setup) - High: Необходимо для валидации производительности

**Метрики для каждой задачи:**
- STORY-001: POST /wishes - p95 ≤ 200ms
- STORY-002: GET /wishes - p95 ≤ 150ms (может быть кеширован)
- STORY-003: PUT /wishes/{id} - p95 ≤ 200ms
- STORY-004: DELETE /wishes/{id} - p95 ≤ 100ms

### NFR-002: Пропускная способность
**Влияет на задачи:**
- **STORY-002** (Получение списка wishes) - High: Самый частый запрос
- **STORY-001** (Создание wish) - Medium: Менее частый, но важный
- **STORY-003** (Обновление wish) - Medium: Средняя частота
- **STORY-004** (Удаление wish) - Medium: Наименее частый
- **TASK-005** (Load testing setup) - High: Критично для валидации

**Ожидаемая нагрузка:**
- GET /wishes: 60% от общего трафика
- POST /wishes: 20% от общего трафика
- PUT /wishes/{id}: 15% от общего трафика
- DELETE /wishes/{id}: 5% от общего трафика

### NFR-003: Доступность системы
**Влияет на задачи:**
- **Все STORY** - High: Система должна быть доступна для всех операций
- **TASK-001** (Настройка мониторинга) - High: Критично для отслеживания
- **TASK-003** (Настройка CI/CD) - High: Автоматизация развертывания
- **TASK-007** (Container orchestration) - High: Обеспечение высокой доступности

**Требования доступности:**
- Uptime ≥ 99.9% для всех endpoints
- Health check каждые 30 секунд
- Автоматический restart при сбоях

### NFR-004: Безопасность данных
**Влияет на задачи:**
- **STORY-001** (Создание wish) - Critical: Защита данных при создании
- **STORY-003** (Обновление wish) - Critical: Защита при изменении
- **STORY-004** (Удаление wish) - Critical: Защита при удалении
- **STORY-002** (Получение списка wishes) - Medium: Защита при чтении
- **TASK-004** (Security scanning) - High: Автоматическая проверка безопасности

**Требования безопасности:**
- Валидация всех входных данных
- Защита от SQL injection
- Логирование всех операций с данными
- Шифрование данных в покое и при передаче

### NFR-005: Валидация входных данных
**Влияет на задачи:**
- **STORY-001** (Создание wish) - High: Валидация при создании
- **STORY-002** (Получение списка wishes) - High: Валидация параметров запроса
- **STORY-003** (Обновление wish) - High: Валидация при обновлении
- **STORY-004** (Удаление wish) - High: Валидация ID

**Схемы валидации:**
- WishCreate: title (1-200), link (0-500), price_estimate (≥0), notes (0-1000)
- WishUpdate: все поля опциональные с теми же ограничениями
- Query parameters: price_lt (float, ≥0)

### NFR-006: Логирование и мониторинг
**Влияет на задачи:**
- **Все STORY** - Medium: Логирование всех операций
- **TASK-001** (Настройка мониторинга) - High: Основная задача
- **TASK-002** (Внедрение логирования) - High: Критично для аудита
- **TASK-003** (Настройка CI/CD) - Medium: Логирование развертываний
- **TASK-004** (Security scanning) - Medium: Логирование сканирований
- **TASK-005** (Load testing setup) - Medium: Логирование тестов

**Требования логирования:**
- Все CRUD операции
- Ошибки и исключения
- Время выполнения запросов
- Пользовательские действия

### NFR-007: Масштабируемость
**Влияет на задачи:**
- **STORY-002** (Получение списка wishes) - Medium: Самый нагруженный endpoint
- **TASK-007** (Container orchestration) - High: Обеспечение масштабируемости

**Требования масштабируемости:**
- Поддержка горизонтального масштабирования
- Stateless архитектура
- Load balancing

### NFR-008: Резервное копирование
**Влияет на задачи:**
- **Все STORY** - Medium: Защита всех данных
- **TASK-006** (Database migration) - High: Критично для миграций
- **TASK-008** (Backup strategy) - High: Основная задача

**Требования резервного копирования:**
- Ежедневные полные бэкапы
- Инкрементальные бэкапы каждый час
- Тестирование восстановления
