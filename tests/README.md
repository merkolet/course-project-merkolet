# Тесты для Wishlist API

## Обзор

Этот набор тестов покрывает все основные функции Wishlist API с покрытием кода 91%.

## Структура тестов

### `test_health.py`
- Тестирование health check endpoint

### `test_wishes.py`
- **TestWishesAPI** - основной класс тестов для API желаний
- Тестирование всех CRUD операций
- Тестирование валидации данных
- Тестирование фильтрации по цене
- Тестирование обработки ошибок

### `test_errors.py`
- Тестирование обработки ошибок
- Тестирование валидации входных данных

## Покрытие кода

- **Общее покрытие**: 91%
- **Покрытые модули**:
  - `app/api/wishes.py` - 100%
  - `app/core/config.py` - 100%
  - `app/main.py` - 100%
  - `app/schemas/wish.py` - 100%

## Запуск тестов

```bash
# Активировать виртуальное окружение
source venv/bin/activate

# Запустить все тесты
python -m pytest tests/ -v

# Запустить с покрытием кода
python -m pytest tests/ --cov=app --cov-report=term-missing

# Запустить конкретный тест
python -m pytest tests/test_wishes.py::TestWishesAPI::test_create_wish_success -v
```

## Фикстуры

- `client` - TestClient для FastAPI
- `sample_wish_data` - Пример данных для тестирования
- `reset_db` - Автоматический сброс базы данных перед каждым тестом

## Тестируемые сценарии

### Успешные операции
- Создание желания с полными данными
- Создание желания с минимальными данными
- Получение всех желаний
- Получение желания по ID
- Обновление желания (полное и частичное)
- Удаление желания
- Фильтрация по цене

### Обработка ошибок
- 404 для несуществующих желаний
- Валидация пустых полей
- Валидация слишком длинных строк
- Валидация отрицательных цен
- Валидация некорректных email (для User схемы)

### Временные метки
- Корректная установка `created_at` и `updated_at`
- Обновление `updated_at` при изменении данных
